# SORANE SR-28

スマホがそのままカセットプレーヤーになる3Dウェブアプリ。

## 公開（GitHub Pages）
1. GitHubで新しいリポジトリ（例: `sorane`）を作る
2. このフォルダの中身をすべてリポジトリの直下にアップロードする
3. Settings → Pages → Branch を `main` / `(root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/sorane/` で開ける

## iPhoneのホーム画面に追加
Safariで上のURLを開く → 共有ボタン → 「ホーム画面に追加」。
ホーム画面から起動すると、最初から全画面プレーヤーで開きます。一度開いたあとはオフラインでも動きます。

## 更新するとき
ファイルを差し替えたら `sw.js` の `VERSION`（例: `sr28-v1` → `sr28-v2`）を上げる。
上げないと、ホーム画面のアプリが古いキャッシュのまま表示されることがあります。
